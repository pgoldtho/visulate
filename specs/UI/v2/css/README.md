# CSS Styles for Visulate UI v2

## Functional Overview
This directory (`specs/UI/v2/css`) contains the core CSS stylesheets responsible for the visual presentation and layout of the Visulate user interface, specifically for version 2. It includes general layout styles, the primary theme, and dedicated styles for print output.

## Files & Component Responsibilities
*   **`2col.css`**: This stylesheet primarily defines styles for tables and data presentation, including generic table structures (`td`, `th`), layout-specific tables (`.layouttable`), and data-centric tables (`.datatable`). It appears to handle aspects of two-column layouts or general tabular data display within the application.
*   **`new_style.css`**: This is the main stylesheet for the Visulate UI v2. It establishes global styles for `html` and `body`, defines the main `#container` width and background, and styles the `#header` section, including the corporate `a.logotype`. It dictates the overall look, feel, and foundational layout of the application.
*   **`print.css`**: This stylesheet provides optimized styles specifically for printing web pages from the Visulate application. It overrides or defines styles for common HTML elements such as headings (`h1-h6`), paragraphs (`p`), images (`img`), lists (`ul`, `ol`, `dl`), links (`a`), blockquotes, and code snippets, ensuring a clean and readable printed output.

## Database Dependencies & Interactions
The CSS files in this directory do not have direct dependencies on or interactions with the database. They are purely concerned with styling the HTML structure generated by the application.
