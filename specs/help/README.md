# specs/help

## Functional Overview

This directory serves as a repository for documentation related to the application's help system, specifically detailing custom error codes and their descriptions. The primary asset here is a binary document that provides specifications for error messages generated by various Oracle PL/SQL packages within the Visulate application. These error codes are typically custom application errors raised from PL/SQL code, with a mapping indicated for a `RNT_ERROR_DESCRIPTION` table.

## Maintenance & Modernization Notes

*   **Binary Document Format**: The `error_code.doc` file is in an outdated binary format, which complicates version control, diffing, and automated parsing. It is highly recommended to convert this document to a more modern, plaintext, or structured format (e.g., Markdown, a database table for error metadata, or a `.csv`/`.json` file) to improve maintainability, searchability, and ease of updates.
*   **Synchronization**: The error codes and their descriptions in this document must remain synchronized with the actual error handling logic in the application's PL/SQL packages and the data in the `RNT_ERROR_DESCRIPTION` table. Any discrepancy can lead to incorrect error reporting or diagnostics.
*   **Centralized Error Handling**: If not already in place, consider implementing a centralized error handling mechanism that programmatically uses or validates against the definitions found in this document to ensure consistency across the application.
